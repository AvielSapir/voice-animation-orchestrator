תמליל חי בזמן אמת (TherapistTranscriptEvent)

ברגע שהילד מסיים לדבר (אחרי תמלול) וכשהדמות עונה, השרת דוחף למסך המטפל שורת תמליל עם זהות הדובר (CHILD או CHARACTER), הטקסט בעברית, וחותמת זמן. 

{
  "sessionId": "session-child-402",
  "turnId": "turn-001",
  "speaker": "CHILD",
  "text": "קצת עצוב לי היום",
  "timestampMs": 1795352010000
}

בקרה והנחיות סמויות (TherapistControlMessage)

המטפל שולח בתחילת החיבור הודעת auth עם ה־JWT שלו, ובמהלך הסשן יכול לשלוח הנחיית live_steering שמועברת אוטומטית מצוות 5 למנוע ה־AI (צוות 3). 

{
  "type": "live_steering",
  "sessionId": "session-child-402",
  "instruction": "תעבור לטון מעודד ותשאל על המשחק",
  "timestampMs": 1795352020000
}

תיאום עם חוזה 4 (צוות 3)

צוות 5 אינו מפרש את תוכן ה־live_steering בעצמו — הוא שומר את ההנחיה האחרונה של הסשן ומצרף אותה בשדה האופציונלי liveSteering בבקשה הבאה אל צוות 3 (AiTurnRequest).
